VIZ TAPE 1.3
An animated cassette for the PSP Music player (6.61 ARK-4 / PRO-C)
Models enabled: PSP-1000, PSP-2000, PSP-3000, PSP Go and PSP Street/E1000.
Compatibility changes tested on PSP-1000 with 6.61 ARK-4 and PRO-C Infinity.

WHAT YOU NEED
  - Your PSP with 6.61 ARK-4 or PRO-C, and a USB cable (or a card reader).
  - viz_tape-v1.3.zip. It contains a "seplugins" folder.

INSTALL
  1. Download viz_tape-v1.3.zip from the GitHub release and unzip it.
     https://github.com/beckerd/psp_viz_tape/releases/tag/v1.3

  2. Connect the PSP in USB mode and copy the ZIP's seplugins folder to the
     root of the memory card. Merge existing folders and replace
     viz_tape.prx if updating. Keep other plugins.

  ARK-4/5
  3. Add this one line to seplugins/PLUGINS.TXT (create the file if needed):

       vsh, ms0:/seplugins/viz_tape/viz_tape.prx, on

     For PSP Go internal storage, install there and use ef0: instead of ms0:.

  PRO-C
  3. Add this one line to seplugins/vsh.txt (create the file if needed):

       ms0:/seplugins/viz_tape/viz_tape.prx 1

     For PSP Go internal storage, install there and use ef0: instead of ms0:.

  Use only the entry for your CFW, and keep one Viz Tape entry. Edit the
  plugin list in plain text (TextEdit: Format > Make Plain Text; Windows:
  Notepad). Keep other plugins' lines and save the file.

  4. Eject, exit USB mode and fully restart the PSP. Play a song in the Music
     player and select the LAST visualizer.

  The first time the PSP starts with Viz Tape, it makes the little cassette
  icon for the visualizer menu during startup, ready for the first Music
  session. Nothing else to do.

UPDATING FROM AN OLDER VERSION
  Keep one Viz Tape line in your CFW's plugin list, using the format above.
  Copy the new seplugins folder over the old one, then restart the
  PSP before opening Music. Delete the old viz_tape_render.prx file; the
  renderer is now included inside viz_tape.prx.
  An enabled.txt from version 1.0 is no longer needed; you can delete it.

TURN OFF OR UNINSTALL
  Turn off:  ARK: change "on" to "off" on the Viz Tape line.
             PRO-C: change the final "1" to "0". Then restart.
  Uninstall: delete that line and the seplugins/viz_tape folder, then restart
             before opening Music again.

IF THE PSP WON'T START PROPERLY
  Viz Tape skips itself for one start if the previous start crashed, so it
  cannot get stuck in a loop. Disable Viz Tape through your CFW's Recovery
  Menu or its plugin list over USB. On ARK, holding START while turning the
  PSP on also skips plugins for one boot.
  ARK's guide: https://github.com/PSP-Archive/ARK-4/wiki/Recovery

IF THE CASSETTE DOESN'T SHOW UP
  Check that the single line is in your CFW's plugin list exactly as above,
  and that seplugins/viz_tape has viz_tape.prx.
  The plugin writes notes to seplugins/viz_tape/status.txt.
  After a failed startup, the recovery boot preserves those notes and adds
  its skip reason. This build identifies itself as 1.3 and records
  the model ID, storage device and user-memory partition.
  A RENDERER load/start failure leaves the stock visualizer selected.

TESTING STATUS
  A fresh 1.3-dev1 install passed startup and Music-hook checks on a
  PSP-1000 with 6.61 ARK-4 on 2026-10-17. The icon generated successfully,
  the user reported good visuals, integrity checks passed and the boot
  guard cleared. The same test build passed on PSP-1000 with 6.61 PRO-C
  Infinity: successful startup, cassette display and reel animation during
  music playback. Version 1.3 keeps that behavior and updates the version
  label. ARK-5, full model coverage, extended playback and suspend/resume
  still need hardware tests. This change does not establish
  that public 1.2 fails on PRO-C.
  ARK may report devkit=06060010 on 6.61; use System Information for the
  installed firmware version. Share status.txt after testing.
